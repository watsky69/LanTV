# 🛡️ PhishGuard

**Интеллектуальная система обнаружения фишинговых веб-ресурсов на основе анализа URL с использованием машинного обучения.**

## 📋 Описание

PhishGuard — программа, которая анализирует текст URL-адреса (ссылки) и с помощью обученной модели машинного обучения определяет, может ли ссылка быть фишинговой.

**Программа НЕ открывает проверяемые сайты и НЕ переходит по ссылкам — анализируется только строка адреса.**

### Возможности
- 🔍 Проверка URL на фишинг с помощью ML-модели
- 📋 Эвристический анализ подозрительных признаков URL
- 📊 Отображение метрик качества модели
- 🛡️ Работа полностью локально, без интернета (после загрузки данных и обучения)

## 🚀 Установка и запуск (Windows)

### Требования
- Python 3.9 или новее
- Windows 10/11

### Шаг 1. Установка зависимостей

Откройте терминал (PowerShell или Командная строка) и перейдите в папку проекта:

```powershell
cd путь\к\PhishGuard
```

Установите необходимые библиотеки:

```powershell
pip install -r requirements.txt
pip install ucimlrepo
```

### Шаг 2. Загрузка набора данных

Запустите скрипт загрузки данных (требуется интернет):

```powershell
python download_data.py
```

Скрипт автоматически скачает набор данных PhiUSIIL из UCI Machine Learning Repository и сохранит его в папку `data/`.

**Альтернативный способ (ручная загрузка):**
1. Откройте страницу: https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+website
2. Скачайте CSV-файл с данными.
3. Поместите его в папку `data/` с именем `dataset.csv`.

### Шаг 3. Обучение модели

Запустите обучение:

```powershell
python train_model.py
```

Скрипт:
- Загрузит данные из `data/`
- Обучит модель (TF-IDF + Logistic Regression)
- Покажет метрики качества
- Сохранит модель в `models/phishguard_model.joblib`

### Шаг 4. Запуск приложения

**Способ 1 (Самый простой):**  
Дважды кликните по файлу **`start.bat`** в папке проекта. Приложение запустится и автоматически откроет браузер.

**Способ 2 (Через терминал):**
```powershell
python run.py
```
или напрямую через Streamlit:
```powershell
streamlit run app.py
```

Приложение автоматически выберет свободный порт и откроется в браузере (по умолчанию `http://localhost:8501`).

## 📊 Набор данных

Используется открытый набор **PhiUSIIL Phishing URL Dataset** из UCI Machine Learning Repository:

- **Источник:** https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+website
- **Содержание:** URL-адреса с метками (легитимный / фишинговый)
- **Метки:** в исходном наборе `label=1` — легитимный, `label=0` — фишинговый

Для обучения модели используется **только текст URL** — никакие дополнительные признаки из набора данных не применяются.

## ⚠️ Ограничения

- Результат является **оценкой модели**, а не гарантией безопасности.
- Модель обучена на конкретном наборе данных и может ошибаться на новых типах фишинга.
- Программа анализирует только текст URL, не проверяя содержимое страниц.
- Это исследовательский проект, не предназначенный для замены антивирусных решений.
