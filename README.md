# 🏆 LanUs CS2 Analytics (v4.0 PRO) — HLTV Rating 3.0 Analog

Профессиональная система глубокого анализа киберспортивных матчей Counter-Strike 2 (CS2) из `.dem` файлов с расчетом рейтинга **LanUs Rating 3.0** (полный аналог HLTV Rating 3.0).

---

## ⚡ Быстрый запуск в 2 клика (на любом компьютере)

1. Убедитесь, что на компьютере установлен **Python 3.10+** *(с галочкой "Add Python to PATH")*.
2. Просто **дважды кликните по файлу**:
   👉 **`ЗАПУСК_LANUS_CS2.bat`** *(или `START.bat`)*

Скрипт автоматически:
- Проверит и доустановит все недостающие библиотеки (`demoparser2`, `pandas`, `starlette`, `uvicorn`).
- Запустит локальный веб-сервер.
- **Сам откроет сайт в вашем браузере** по адресу `http://localhost:8080`.

---

## 🚀 Возможности Версии 4.0 PRO

1. **Универсальность (любые демки)**:
   - Автоматически рассчитывает стандартные матчи (MR12), матчи старого формата (MR15) и матчи с **любым количеством овертаймов** (OT1, OT2...).
   - Реальное отслеживание счета и сторон команд по каждому раунду.

2. **Строгая фильтрация (.dem Filter)**:
   - Полное отсечение разминки (`Warmup Phase`).
   - Идентификация и автоматическое удаление ножевых раундов (`Knife Round`).
   - Исключение технических рестартов (`mp_restartgame`).

3. **Расчет важности клатчей (1v1, 1v2, 1v3, 1v4, 1v5)**:
   - Фиксация момента, когда игрок остается один против соперников.
   - Оценка вытащенных клатчей в Round Swing (+76% за 1v2, +92% за 1v3).
   - Прямой вклад в суб-рейтинг $R_{Impact}$.

4. **Экономическая корректировка (Eco-Adjustment)**:
   - Взвешивание ценности каждого убийства по соотношению экипировки: `Kill_Value = Base_Kill * sqrt(Cost_Opponent / Cost_My)`.
   - Штраф за набивку статистики на безбронных эко-раундах.
   - Бонус за фраги под давлением (пистолет против фулл-бая).

5. **Round Swing (Влияние на исход раунда)**:
   - Оценка смещения вероятности победы команды в раунде ($\Delta Win Probability$).
   - Штрафы за эксит-фраги при сейвах.
   - Справедливое распределение очков между киллером, ассистом и разменами.

6. **Итоговая формула LanUs Rating 3.0**:
   ```
   LanUs_Rating_3.0 = (0.25 * R_Kill_Eco) + (0.15 * R_Survival) + (0.20 * R_Damage_Eco) + (0.20 * R_RoundSwing) + (0.10 * R_Impact) + (0.10 * R_KAST)
   ```
   Все 6 суб-показателей нормируются к матчевым средним (средний рейтинг ~1.00 - 1.05).

## 📁 Структура файлов

- `ЗАПУСК_LANUS_CS2.bat` — лаунчер в 2 клика (проверка, установка зависимостей, автооткрытие браузера).
- `engine_v4.py` — универсальное ядро парсинга и расчетов LanUs Rating 3.0.
- `server.py` — веб-сервер на Starlette + Uvicorn с REST API.
- `templates/index.html` — современный киберспортивный веб-интерфейс (Tailwind CSS, Lucide, Chart.js).
- `lanus_analyzer.py` — CLI версия для запуска напрямую из терминала (`python lanus_analyzer.py "путь.dem"`).
- `requirements.txt` — список зависимостей Python.
